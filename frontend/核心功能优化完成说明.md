## 🎨 设计特点

### 视觉设计
- **渐变配色**：每个宇宙使用不同的渐变主题色
- **毛玻璃效果**：backdrop-filter实现现代感
- **圆角设计**：统一的16-20px圆角
- **阴影效果**：多层次的阴影营造深度感

### 动画效果
- **Framer Motion**：流畅的进入/退出动画
- **延迟动画**：卡片依次出现（stagger效果）
- **悬停动画**：上浮、阴影加深
- **进度条动画**：从0增长到实际值

### 交互设计
- **卡片点击**：展开详情抽屉
- **模式切换**：表格/雷达图/卡片三种模式
- **数据排序**：表格支持多列排序
- **响应式布局**：适配不同屏幕尺寸

## 🚀 使用方法

### 1. 安装依赖

```bash
cd frontend
npm install
# 或
pnpm install
```

### 2. 生成报告

1. 在对话界面发送消息
2. 点击头部"生成报告"按钮
3. 等待报告生成（显示加载状态）
4. 报告在模态框中展示

### 3. 查看报告内容

- **平行宇宙标签**：查看所有宇宙卡片
- **对比分析标签**：切换不同的对比模式
- **点击卡片**：查看宇宙详情
- **点击对比按钮**：快速跳转到对比视图

## 🔧 技术实现

- **图表库**：Recharts（雷达图）

- **UI框架**：Ant Design（基础组件）
- **样式**：CSS Modules + 自定义CSS
- **类型安全**：完整的TypeScript类型定义

## 📝 注意事项

1. **数据格式**：报告数据解析依赖于后端返回的格式，如果格式变化需要调整`reportParser.ts`
2. **性能优化**：如果报告数据量大，可以考虑虚拟滚动
3. **浏览器兼容**：需要支持CSS backdrop-filter（现代浏览器）

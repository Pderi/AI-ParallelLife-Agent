# 页面空白问题排查指南

## 🔍 可能的原因

1. **依赖未安装**：新添加的依赖（framer-motion, recharts）未安装
2. **初始化错误**：创建会话失败导致组件崩溃
3. **导入错误**：组件导入路径错误
4. **构建错误**：TypeScript或构建错误

## ✅ 解决步骤

### 1. 安装依赖

```bash
cd frontend
npm install
# 或
pnpm install
```

确保以下依赖已安装：
- `framer-motion`
- `recharts`

### 2. 检查浏览器控制台

打开浏览器开发者工具（F12），查看：
- **Console标签**：是否有JavaScript错误
- **Network标签**：请求是否正常
- **Sources标签**：是否有文件加载失败

### 3. 检查终端输出

查看前端开发服务器的输出，是否有：
- 编译错误
- 模块找不到错误
- TypeScript错误

### 4. 清除缓存重新启动

```bash
# 清除node_modules和缓存
cd frontend
rm -rf node_modules
rm -rf .vite
npm cache clean --force

# 重新安装
npm install

# 重新启动
npm run dev
```

### 5. 检查环境变量

确保 `.env` 文件存在且配置正确：
```env
VITE_API_BASE_URL=/api
VITE_APP_TITLE=平行宇宙人生模拟器
```

## 🐛 常见错误

### 错误1: Cannot find module 'framer-motion'

**解决方案**：
```bash
npm install framer-motion
```

### 错误2: Cannot find module 'recharts'

**解决方案**：
```bash
npm install recharts
```

### 错误3: 初始化会话失败

**已修复**：即使创建会话失败，也会生成临时ID，避免页面无法使用

### 错误4: 组件导入错误

检查所有导入路径是否正确，特别是：
- `@/components/Report/ReportModal`
- `@/components/Chat/ChatList`
- `@/components/Chat/ChatInput`

## 🔧 临时解决方案

如果问题仍然存在，可以临时注释掉报告相关功能：

1. 在 `App.tsx` 中注释掉 `ReportModal` 导入和使用
2. 检查页面是否能正常显示
3. 逐步恢复功能，定位问题

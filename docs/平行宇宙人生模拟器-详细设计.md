# 平行宇宙人生模拟器（ParallelLifeApp）详细设计文档

## 1. 核心概念

### 1.1 产品定位

**平行宇宙人生模拟器**是一个基于AI的个性化人生探索工具，通过模拟不同人生路径，帮助用户：
- 探索人生可能性
- 理解决策的影响
- 获得人生规划建议
- 以游戏化的方式思考人生

### 1.2 设计理念

> "如果当初我选择了另一条路，现在会怎样？"

每个人在人生中都会面临无数选择，每个选择都会开启不同的人生路径。这个应用通过AI模拟，让用户能够"预览"不同选择可能带来的结果，从而：
- **减少后悔**：通过模拟了解不同选择的后果
- **增强决策力**：基于模拟结果做出更明智的选择
- **激发思考**：从不同角度审视自己的人生
- **规划未来**：基于模拟结果制定人生规划

## 2. 核心功能设计

### 2.1 人生路径模拟（LifePathSimulation）

#### 功能描述
用户输入当前情况或假设场景，AI模拟不同选择路径的发展。

#### 使用场景示例
```
用户："如果我大学选择了计算机专业而不是金融，现在会怎样？"
AI：生成3-5条不同的平行人生路径，包括：
- 路径A：成为软件工程师，在互联网公司工作
- 路径B：创业做技术产品
- 路径C：成为技术专家，在大型企业做架构师
- 路径D：转行做产品经理
- 路径E：继续深造，成为AI研究员
```

#### 模拟维度
每条路径包含：
- **职业发展**：职位、薪资、工作内容
- **生活状态**：居住城市、生活方式、社交圈
- **个人成长**：技能发展、知识积累、性格变化
- **人际关系**：可能遇到的人、关系网络
- **时间线**：1年、3年、5年、10年的发展节点
- **关键事件**：重要转折点、机遇、挑战

### 2.2 决策影响分析（DecisionImpactAnalysis）

#### 功能描述
分析特定决策在多个平行宇宙中的影响。

#### 使用场景
```
用户："我想辞职去创业，帮我分析一下不同结果"
AI：分析三种平行宇宙：
- 宇宙A：创业成功，实现财务自由
- 宇宙B：创业失败，但积累了经验，找到更好的工作
- 宇宙C：创业中途放弃，回到职场但错过了晋升机会
```

#### 分析维度
- **成功概率**：基于行业数据和个人情况
- **风险等级**：高/中/低风险
- **时间成本**：需要投入的时间
- **机会成本**：放弃其他选择的机会
- **情感影响**：对个人幸福感的影响
- **长期影响**：5-10年后的可能状态

### 2.3 人生可能性探索（LifePossibilityExploration）

#### 功能描述
基于用户当前状态，探索所有可能的人生路径。

#### 使用场景
```
用户："我今年25岁，程序员，想探索一下未来10年可能的人生"
AI：生成多个平行宇宙：
- 宇宙1：技术专家路径（继续深耕技术）
- 宇宙2：管理路径（转向管理岗位）
- 宇宙3：创业路径（自主创业）
- 宇宙4：转行路径（转向其他行业）
- 宇宙5：自由职业路径（成为独立开发者/咨询师）
- 宇宙6：学术路径（继续深造）
```

#### 探索维度
- **职业路径**：不同职业发展方向
- **生活方式**：不同生活模式
- **地理位置**：不同城市/国家
- **关系状态**：不同的人际关系选择
- **价值观**：不同的价值追求

### 2.4 场景模拟（ScenarioSimulation）

#### 功能描述
模拟特定场景下的不同发展。

#### 场景类型

**1. 职业场景**
- "如果我现在跳槽到另一家公司会怎样？"
- "如果我转行做产品经理会怎样？"
- "如果我选择创业会怎样？"

**2. 生活场景**
- "如果我搬到另一个城市会怎样？"
- "如果我选择不结婚会怎样？"
- "如果我选择丁克会怎样？"

**3. 学习场景**
- "如果我选择读研会怎样？"
- "如果我选择出国留学会怎样？"
- "如果我选择学习新技能会怎样？"

**4. 关系场景**
- "如果我选择分手会怎样？"
- "如果我选择结婚会怎样？"
- "如果我选择修复关系会怎样？"

### 2.5 人生报告生成（LifeReportGeneration）

#### 功能描述
生成结构化的"平行人生报告"，包含多个宇宙的对比分析。

#### 报告结构

```java
record ParallelLifeReport(

    String currentSituation,           // 当前情况

    Recommendations recommendations    // 建议

record ParallelUniverse(
    String universeName,               // 宇宙名称（如"技术专家宇宙"）
    String description,                // 宇宙描述
    LifePath lifePath,                 // 人生路径
    List<KeyEvent> keyEvents,         // 关键事件
    LifeMetrics metrics,               // 人生指标
    String probability                 // 实现概率
)

record LifePath(
    List<TimePoint> timeline,         // 时间线（1年、3年、5年、10年）
    CareerDevelopment career,          // 职业发展
    PersonalGrowth personal,          // 个人成长
    RelationshipStatus relationships,  // 人际关系
    Lifestyle lifestyle                // 生活方式
)

record LifeMetrics(
    int happinessScore,               // 幸福感评分（1-100）
    int financialScore,               // 财务状况评分
    int growthScore,                  // 成长潜力评分
    int stabilityScore,               // 稳定性评分
    int riskLevel                      // 风险等级（1-10）
)
```

### 2.6 人生规划建议（LifePlanningAdvice）

#### 功能描述
基于模拟结果，提供具体的人生规划建议。

#### 建议类型

**1. 路径选择建议**
- 推荐最适合的路径
- 说明推荐理由
- 提供实施步骤

**2. 风险规避建议**
- 识别潜在风险
- 提供风险应对策略
- 建议备选方案

**3. 能力提升建议**
- 识别所需技能
- 提供学习路径
- 推荐学习资源

**4. 时机把握建议**
- 分析最佳行动时机
- 提供时间规划
- 识别关键时间节点

### 4.1 首次使用流程

```

   - 宇宙A：继续做程序员
   - 宇宙B：转行做产品经理
   - 宇宙C：内部转岗

### 4.2 多轮对话流程

```
用户："我想深入了解宇宙B（转行做产品经理）"
   ↓
AI："好的，让我为你详细展开这个宇宙..."
   - 详细的时间线
   - 每个阶段的具体情况
   - 需要的技能和能力
   - 可能遇到的挑战
   ↓
用户："这个路径的成功概率是多少？"
   ↓
AI："基于你的情况分析，成功概率约为65%..."
   - 正面因素分析
   - 负面因素分析
   - 提升概率的建议
   ↓
用户："如果我想提高成功率，应该怎么做？"
   ↓
AI："建议你采取以下行动..."
   - 能力提升建议
   - 学习路径
   - 实践建议
   - 时间规划
```

```
用户："生成PDF报告"
   ↓
系统调用PDFGenerationTool
   ↓
生成包含以下内容的PDF：
   - 封面：平行人生报告
   - 当前情况分析
   - 平行宇宙详细描述（每个宇宙一页）
   - 对比分析图表
   - 建议和行动计划
   ↓
保存到 tmp/pdf/ 目录
   ↓
返回文件路径给用户

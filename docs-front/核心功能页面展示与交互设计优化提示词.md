# 平行宇宙人生模拟器 - 核心功能页面展示与交互设计优化提示词

## 📋 项目背景

你需要为"平行宇宙人生模拟器"的核心功能设计独特的页面展示和交互体验。这是一个基于AI的人生规划应用，核心功能是模拟多个平行宇宙的人生路径，帮助用户探索不同选择的可能性。

### 核心功能特点
- **平行宇宙模拟**：生成3-5个不同的平行人生路径
- **多维度分析**：职业发展、财务状况、个人成长、生活方式、人际关系、幸福感
- **时间线展示**：1年、3年、5年、10年的发展节点
- **关键事件**：重要转折点和机遇
- **人生指标**：幸福感、财务状况、成长潜力等（1-100分）
- **实现概率**：基于客观因素评估的成功概率
- **对比分析**：不同路径的优劣对比
- **专业建议**：基于分析的建议列表

---

## 🎨 设计理念

### 核心概念：平行宇宙
- **视觉隐喻**：多个并行的宇宙空间，每个代表一种人生可能性
- **交互隐喻**：在不同宇宙间切换、对比、探索
- **情感连接**：让用户感受到"如果选择了另一条路会怎样"的探索感

### 设计原则
1. **沉浸感**：营造探索平行宇宙的沉浸式体验
2. **对比性**：突出不同路径的差异和特点
3. **可视化**：用图表、时间线等直观展示数据
4. **交互性**：丰富的交互让用户主动探索
5. **情感化**：通过设计传达"人生选择"的庄重感

#### 1.2 宇宙卡片设计

**视觉设计：**
- **卡片样式**：
  - 毛玻璃效果（backdrop-filter）
  - 渐变边框（每个宇宙不同颜色）
  - 阴影和光晕效果
  - 悬停时轻微放大和阴影加深
  
- **颜色方案**：
  - 每个宇宙使用不同的主题色
  - 技术路径：蓝色系（#667eea → #764ba2）
  - 产品路径：紫色系（#f093fb → #f5576c）
  - 创业路径：橙色系（#ffecd2 → #fcb69f）
  - 管理路径：绿色系（#a8edea → #fed6e3）
  
- **卡片内容**：
  ```
  ┌─────────────────────────────┐
  │  🌟 技术专家路径            │
  │  ────────────────────────   │
  │  继续深耕技术，成为领域专家  │
  │                             │
  │  📊 实现概率：70%           │
  │  ⭐ 综合评分：85/100        │
  │                             │
  │  [查看详情] [对比]          │
  └─────────────────────────────┘
  ```

**交互设计：**
- **点击卡片**：展开详细视图（抽屉或模态框）
- **悬停效果**：卡片轻微上浮，显示预览信息
- **选中状态**：高亮边框，背景色加深
- **快速预览**：悬停时显示关键指标

#### 1.3 时间线可视化

**设计需求：**
- **时间轴样式**：
  - 垂直时间轴（从上到下：1年 → 3年 → 5年 → 10年）
  - 或水平时间轴（从左到右）
  - 每个时间节点用圆点标记
  - 节点间用线条连接
  
- **时间节点内容**：
  ```
  2026年（1年后）
  ├─ 职位：高级工程师
  ├─ 薪资：25k/月
  ├─ 关键成就：参与核心项目
  └─ 生活状态：工作稳定，开始考虑买房
  ```

- **交互效果**：
  - 点击时间节点：展开详细信息
  - 滚动时间轴：平滑滚动到对应年份
  - 动画效果：时间轴从当前时间点展开

**实现建议：**
- 使用时间轴组件（如 react-vertical-timeline 或自定义）
- 支持缩放（查看不同时间范围）
- 支持对比模式（多个宇宙的时间线并排显示）

#### 1.4 人生指标可视化

**雷达图（推荐）：**
```
        幸福感
           ╱ ╲
          ╱   ╲
   成长潜力    财务状况
      ╲       ╱
       ╲     ╱
        稳定性
```

**设计需求：**
- **指标维度**：
  - 幸福感（1-100）
  - 财务状况（1-100）
  - 成长潜力（1-100）
  - 稳定性（1-100）
  - 工作生活平衡（1-100）
  
- **可视化方式**：
  - 雷达图：展示多维度对比
  - 进度条：单项指标展示
  - 仪表盘：综合评分展示
  - 热力图：多个宇宙的指标对比

**交互设计：**
- **悬停提示**：显示具体数值
- **对比模式**：多个宇宙的雷达图叠加显示
- **动画效果**：指标从0增长到实际值

#### 1.5 关键事件展示

**设计需求：**
- **事件卡片**：
  - 不同类型事件用不同图标和颜色
  - 机遇：绿色，向上箭头
  - 挑战：橙色，警告图标
  - 转折点：蓝色，转折图标
  
- **时间线集成**：
  - 事件显示在时间轴上
  - 点击事件查看详情
  - 事件之间的关联线

**交互设计：**
- **事件筛选**：按类型筛选（机遇/挑战/转折点）
- **事件详情**：点击展开详细描述和影响分析
- **事件对比**：对比不同宇宙的同类事件

## 🎭 独特交互设计

### 1. 宇宙切换动画

**设计需求：**
- **切换效果**：
  - 当前宇宙淡出
  - 新宇宙从侧面滑入
  - 或使用3D翻转效果
  - 或使用粒子消散效果
  
- **过渡时间**：300-500ms
- **缓动函数**：ease-in-out

### 2. 时间轴滚动交互

**设计需求：**
- **滚动触发**：
  - 滚动页面时，时间轴自动高亮当前时间点
  - 支持拖拽时间轴快速跳转
  - 支持缩放查看不同时间范围
  
- **动画效果**：
  - 时间节点依次出现（stagger动画）
  - 时间线从当前时间点展开

### 3. 指标动画效果

**设计需求：**
- **加载动画**：
  - 指标从0增长到实际值
  - 使用缓动函数（ease-out）
  - 持续时间：1-2秒
  
- **对比动画**：
  - 切换宇宙时，指标平滑过渡
  - 多个宇宙对比时，指标同时增长

### 4. 3D/视差效果（可选）

**设计需求：**
- **卡片3D效果**：
  - 鼠标移动时，卡片轻微3D倾斜
  - 使用CSS transform: perspective()
  
- **背景视差**：
  - 滚动时，背景和前景不同速度移动
  - 营造深度感

### 5. 粒子/星空效果（可选）

**设计需求：**
- **背景效果**：
  - 使用Canvas或WebGL绘制粒子系统
  - 模拟星空或宇宙背景
  - 粒子随鼠标移动或时间变化
  
- **交互效果**：
  - 点击卡片时，粒子向卡片聚集
  - 切换宇宙时，粒子重新分布

### 1. 动画性能

- 使用CSS transform代替position改变
- 使用will-change提示浏览器优化
- 避免触发重排和重绘

### 2. 渲染优化

- 虚拟滚动（如果列表很长）
- 懒加载（图片、图表）
- 代码分割（按路由）
- 使用React.memo优化组件

### 3. 数据加载

- 分页加载（如果数据量大）
- 骨架屏（加载状态）
- 错误重试机制

## 📚 技术实现建议

### 1. 图表库

**推荐选项：**
- **Recharts**：React图表库，支持雷达图、折线图等
- **ECharts**：功能强大，支持复杂图表
- **D3.js**：高度自定义，但学习曲线陡

### 2. 动画库

**推荐选项：**
- **Framer Motion**：React动画库，功能强大
- **React Spring**：物理动画库
- **GSAP**：专业动画库

### 3. 时间轴组件

**推荐选项：**
- **react-vertical-timeline**：垂直时间轴
- **react-chrono**：时间轴组件
- **自定义实现**：使用SVG或Canvas

### 4. 3D效果

**推荐选项：**
- **Three.js**：3D库（如果使用3D效果）
- **CSS 3D Transform**：简单3D效果
- **Lottie**：动画库

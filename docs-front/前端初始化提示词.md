# 前端项目初始化提示词

## 📋 项目背景

你需要为一个名为"平行宇宙人生模拟器"的AI应用开发前端项目。这是一个基于Spring Boot + Spring AI的后端项目，前端目录目前为空，需要从零开始构建。

### 项目核心功能
- **AI对话系统**：与AI进行多轮对话，探索人生可能性
- **流式响应**：支持Server-Sent Events (SSE)实时流式输出
- **平行人生模拟**：模拟3-5个不同的平行宇宙人生路径
- **结构化报告**：生成包含多个平行宇宙详细分析的报告
- **RAG增强**：结合知识库提供专业建议（可选）
- **工具调用**：支持网络搜索、PDF生成等工具（可选）

### 后端API信息
- **Base URL**: `http://localhost:8123/api`
- **API文档**: `http://localhost:8123/api/swagger-ui.html`
- **Content-Type**: `application/json`
- **流式响应**: `text/event-stream` (SSE)

## 🔌 API对接要求

### 必须实现的接口

#### 1. 创建会话
```typescript
POST /api/parallel-life/session
Request: { userId?: string, sessionName?: string }
Response: { code: 200, data: { chatId, userId, sessionName, createTime, updateTime } }
```

#### 2. 流式对话（核心接口，必须实现）
```typescript
POST /api/parallel-life/chat/stream
Content-Type: application/json
Accept: text/event-stream
Request: { message: string, chatId: string, useRag?: boolean, useTools?: boolean }
Response: Server-Sent Events (SSE)
```

**流式处理要求**:
- 使用 `EventSource` 或 `Fetch API` 处理SSE流
- 实时显示AI回复内容（打字效果）
- 正确处理流式数据格式（`data: xxx`）
- 处理流结束事件
- 处理流错误事件

#### 3. 快速流式对话（简化版，可选但推荐）
```typescript
POST /api/parallel-life/quick-chat/stream
Content-Type: application/json
Accept: text/event-stream
Request: string (直接发送消息字符串)
Response: Server-Sent Events (SSE)
```

#### 4. 生成报告
```typescript
POST /api/parallel-life/report
Request: { message: string, chatId: string }
Response: { code: 200, data: ParallelLifeReport }
```

**报告数据结构**:
```typescript
interface ParallelLifeReport {
  title: string;
  currentSituation: string;
  universes: Universe[];
  comparison: string;
  recommendations: string[];
}

interface Universe {
  name: string;
  description: string;
  timeline: string;
  keyEvents: string[];
  metrics: string;
  probability: string;
}
```

### 可选实现的接口
- 基础对话（非流式）：`POST /api/parallel-life/chat`
- 快速对话（非流式）：`POST /api/parallel-life/quick-chat`
- 获取会话信息：`GET /api/parallel-life/session/{chatId}`

### API调用规范
- **统一错误处理**: 所有API调用需要统一的错误处理机制
- **请求拦截器**: 添加请求头、处理认证（如果需要）
- **响应拦截器**: 统一处理响应格式、错误码
- **超时设置**: 流式接口建议设置较长的超时时间（如5分钟）
- **重试机制**: 网络错误时支持重试（最多3次）

// 使用Fetch API处理SSE流
async function streamChat(message: string, chatId: string) {
  const response = await fetch(`${API_BASE_URL}/parallel-life/chat/stream`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message, chatId })
  });
  
  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    
    const chunk = decoder.decode(value);
    // 处理流式数据，实时更新UI
    handleStreamChunk(chunk);
  }
}

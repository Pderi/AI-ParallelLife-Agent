## 维护约定

1. **只增不乱**：新文档先定类型再落目录，禁止继续堆在 `docs-back/` 根目录。
2. **同主题多版本**：在本 README 标明「当前优先」与「参考/历史」，避免默默分叉。
3. **跨目录引用**：文内链接请使用相对路径（如 `../04-数据与持久化/xxx.md`）。

# 基础设施与数据库环境准备 — 任务清单（进度追踪）

> **与 `MEMORY.md` 对齐**：**首期**个人项目以 **PostgreSQL（含 pgvector）单库** 跑通三层记忆闭环；**MySQL、Redis** 及三库 DDL 为**扩展**，对应 Phase **B / D / G** 可在首期**整段跳过**，待扩展架构时再勾选。  
> **首期 DDL 权威来源**：`docs-back/简化实现方案.md` **第四节**（`users`、`hot_memory`、`warm_memory`、`cold_memory`、`rag_knowledge`）。

## 使用说明

- 每条任务前用 `- [ ]` / `- [x]` 勾选，或填「完成日期」「备注」。
- **首期最短路径**：完成 **Phase A（部分）+ C + E（PG 部分）+ F（PG 验证）** 即可开始业务开发。

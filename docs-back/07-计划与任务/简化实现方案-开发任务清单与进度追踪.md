## 二、方案映射（简化文档 ↔ 本仓库 · 首期单 PG）

| 简化方案概念 | 首期本仓库落地（单 PostgreSQL） |
| --- | --- |
| `users` | 同表；`UserService` + JDBC/MyBatis/JPA |
| `hot_memory` | 同表；热层从 DB 读（非 Redis） |
| `warm_memory` | 同表；向量列 + pgvector 检索 |
| `cold_memory` | 同表；每轮 `query/answer` 落盘；`session_id` 与 API 约定一致 |
| `rag_knowledge` | 同表；RAG 向量检索 |
| `getHotMemory` / `recallWarmMemory` / `recallRAG` | `ContextManager` + 各 Provider；**Hot** 组合：`hot_memory` 行 + 最近 N 条 `cold_memory`（对齐简化方案五、165） |
| `appendColdMemory` → `extractColdToWarm` | 写 `cold_memory` → **异步**提炼 → 写/更 `warm_memory` → `UPDATE hot_memory.global_index`（**均在 PG 事务/连接内**） |
| Express `/api/chat` | 现有 `ParallelLifeController` + 编排下沉至 Service；路径可与文档对齐或保持 `/api` 前缀 |

**扩展（非首期必做）**：会话/消息独立 MySQL 表、Redis 热 key、Outbox、RabbitMQ — 见文末 **Phase X***。
